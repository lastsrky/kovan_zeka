Bu klasör (web_site/), yarışma alanında ve saha operasyonlarında internete veya harici bir sunucuya ihtiyaç duymadan ya da herhangi bir web barındırma (hosting/cPanel/GitHub Pages) hizmetinde çalışabilen **bağımsız web portalı dosyalarını** içerir.

---

## 📂 Klasör İçeriği

| Dosya | Açıklama |
| :--- | :--- |

## 🚀 Nasıl Kullanılır?

### 1. Yerel Kullanım (İnternetsiz / Çevrimdışı)
- **index.html** dosyasına çift tıklayarak doğrudan Chrome, Edge, Safari veya Firefox üzerinde açabilirsiniz.
- Herhangi bir Python, Node.js veya web sunucusuna gerek yoktur. Tüm arama ve filtreleme motoru tarayıcı belleğinde anında çalışır.

### 2. Web Hosting / cPanel (FTP) ile Yayınlama
- Klasördeki **index.html** dosyasını hostinginizin public_html (veya www) dizinine yüklemeniz yeterlidir.

### 3. GitHub Pages ile Yayınlama
- Proje GitHub reponuzda (main branch) Settings -> Pages menüsünden sitenizi anında canlıya alabilirsiniz.
- CNAME dosyası sayesinde contaliesanjor.com alan adınız otomatik olarak bağlanacaktır.
